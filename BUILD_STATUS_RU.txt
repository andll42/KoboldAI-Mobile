НЕ ВЫПОЛНЕНО:
- Не скачан сетевая командами файл upstream index.html в локальный каталог сборки.
- Не запускался npx cap add/sync.
- Не выполнялся Gradle assembleDebug.
- Не собирался APK и не тестировался физический Android-телефон.

Причина: в среде подготовки отсутствуют Android SDK / ANDROID_HOME / ANDROID_SDK_ROOT и Gradle. APK не приложен, чтобы не выдавать несобранный файл за рабочее приложение.

Для получения APK на Windows: установите Node.js 22+, Python 3.10+, Android Studio 2025.2.1+ и Android SDK, затем запустите build-android.bat.
Ожидаемый путь после успешной сборки:
android\app\build\outputs\apk\debug\app-debug.apk
