KoboldAI Mobile Android — v0.2.1, три ASR-провайдера

РЕАЛИЗОВАНО В ИСХОДНИКАХ:
- Capacitor Android shell для официального KoboldAI Lite, проверка LITEVER 341 и набора upstream-якорей (fail-closed; при несовпадении сборка остановится).
- ASR Provider menu: Built-in KoboldCpp Whisper / GigaSTT / Android On-device ASR.
- Built-in KoboldCpp Whisper сохраняет штатный /api/extra/transcribe.
- GigaSTT использует multipart/form-data и настраиваемые base URL/endpoint/model/key/language.
- Android native Capacitor plugin использует только SpeechRecognizer.createOnDeviceSpeechRecognizer().
- Язык Android ASR по умолчанию ru-RU.
- Проверка on-device службы; на API33+ запрос installed/supported/pending языковых моделей.
- Явная кнопка request model download; модель не скачивается автоматически.
- Нет online recognizer fallback.
- Android live-mic path интегрирован с Detect Voice, Push-To-Talk и Toggle-To-Talk.
- Android Detect Voice использует системное определение конца фразы; PTT и Toggle буферизуют фразы до отпускания/повторного нажатия и отправляют единый текст.
- Android no-match/timeout/busy не отключает весь Voice Input.
- Для Android ASR файл аудио не загружается: провайдер работает с live microphone.
- GigaSTT /models и /ready checks — GET-only и не отправляют звук.
- Workflow GitHub Actions и Windows build script обновлены.

ПРОВЕРКИ В ЭТОЙ СРЕДЕ:

НЕ ВЫПОЛНЕНО:
- npm install и esbuild bundle.
- Загрузка upstream Lite во время build.
- npx cap add/sync.
- Gradle assembleDebug / APK build.
- Запуск на Android эмуляторе или POCO M5s.
- Проверка реальной доступности offline ru-RU языковой модели в POCO M5s.
- Проверка реального микрофона, GigaSTT/Whisper, LLM streaming и TTS на устройстве.

Причина: в среде нет Android SDK/ANDROID_HOME/ANDROID_SDK_ROOT/Gradle и физического Android-устройства. Нельзя утверждать, что APK уже собран или мобильный ASR проверен на телефоне.

Получение APK: отправить ветку mobile/android-apk в GitHub; дождаться успешного Actions workflow и скачать KoboldAI-Mobile-debug-apk artifact.
